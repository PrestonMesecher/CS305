Artemis Financial was a financial services company that wanted to improve the security of its application and protect customer information. My task was to make changes that would help protect data and improve secure communications. I think I did well with reviewing the code and using the dependency check to identify security issues. Secure coding is important because it helps protect information and prevent problems that could affect a company and it's customers. One of the more challenging parts was reviewing the dependency check results because there were several vulnerabilities that still needed attention. It also helped me understand why testing is important even when an application appears to be working correctly.

I improved the application's security by adding SHA-256 hashing and using HTTPS with a self-signed certificate. In the future I would use dependency checks and code reviews to identify possible vulnerabilities and determine what needs to be fixed. After making the changes I ran the application and checked that the webpage displayed my name and the SHA-256 checksum. I also ran another dependency check to look for vulnerabilities. Some of the tools I used included Eclipse and OWASP Dependency-Check along with certificate generation and SHA-256. I think these will be useful in future projects where I need to test code and improve security. I could also show employers my completed report to demonstrate how I made changes to an application and tested the results.
